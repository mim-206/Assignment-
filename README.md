ASSIGNMENT
App - SNAPCHAT; Tech stack used

FRONTEND (Mobile)

Languages: Java (Android) & Objective-C / Swift (iOS)
   Used because they are native languages that provide high performance and smooth camera/video integration.

 BACKEND

Python
  Used for rapid development and scalability of core backend services.
Java
  Used for high-performance, large-scale systems that handle heavy traffic reliably.

INFASTRUCTURE / CLOUD

  Google Cloud Platform
   Used to scale storage and computing resources dynamically as millions of users send snaps.
  Amazon Web Services
   Used for reliable cloud infrastructure and global content delivery.

DATABASE & STORAGE

Apache Cassandra
   Used because it handles massive amounts of data across distributed systems with high availability.
  Google Bigtable
   Used for fast, large-scale data storage and retrieval.

REAL TIME & MESSAGING

Apache Kafka
   Used to process real-time data streams like messages and notifications efficiently.

Multimedia Processing

FFmpeg
  Used for compressing, processing, and delivering photos and videos quickly.
